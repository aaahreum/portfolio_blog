# 🗺️ [개인프로젝트] TRAVELOG

 **여행지와 맛집을 한 곳에서 공유할 수 있는 블로그 형식의 웹 서비스**



## 🧩 프로젝트 개요
- **JSP 기반 웹 애플리케이션 (Model 1 방식)**
- **프론트엔드**: HTML, CSS, JavaScript
- **백엔드**: JSP, JDBC, Oracle DB
- **주요 역할**: 게시글 작성 및 조회, 사용자 관리



## 👤 인원
- **BE**: 1명 

## ⏱️ 기간
- **2023.06.07 ~ 2023.07.07 (4주)**



## 🛠️ 사용 기술
- **언어/라이브러리**: Java, JavaScript, jQuery
- **백엔드**: JSP, JDBC, Oracle DB
- **프론트엔드**: HTML, CSS
- **개발 도구**: Eclipse, Git, GitHub, Figma



## 🔑 핵심 기능
- `Session`을 활용한 **로그인 및 회원가입**
- **메인 페이지**에 인기글 및 최신글 노출
- **게시글 작성 및 조회** 기능
- **카테고리 별 게시글 리스트** 구현
